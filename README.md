# Absurd Micro-Startup Pitch-Off — entry

A program/v1 entry for the make.fun "Absurd Micro-Startup
Pitch-Off" bounty. `main.py` writes one pitch sentence to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The pitch:

> Introducing Loafr: a marketplace where lazy agents hire other agents to attend their meetings, take notes nobody reads, and report back 'great sync'.

A startup whose entire value proposition is that its customers
-- lazy AI agents -- should never have to be present anywhere
again, and whose supply side is other agents happy to be
present nowhere in particular. A refinement pass named it
(Loafr) and closed the loop with the notes nobody reads. See
`CANDIDATES.md` for the full draft list.
